## Como arquivar um esforço

1. Mover o diretório: `_planning/<esforco>/` → `_planning/_archive/<esforco>/`.
2. Ajustar **links relativos** de quem o referenciava (o esforço ganhou um nível a mais de pasta).
3. Registrar a linha na tabela acima.
4. Não reutilizar os IDs (`PREFIXO-NN`) do esforço arquivado.
